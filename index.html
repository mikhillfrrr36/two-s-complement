THEORY OF COMPUTATION — FINITE STATE TRANSDUCER

Two's Complement, Bit by Bit

A 2-state Mealy machine that computes the two's complement of an arbitrarily long binary string, reading strictly right to left. It copies bits until it meets the first 1, then flips every bit after that. No lookahead, no backtracking — one bit of memory (the current state) is enough.
